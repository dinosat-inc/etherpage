# DA3 is DA3r. In Halmos 0.3.3 DA3 depends on two 1 ms queries that tell the default entry from the entry of the
# symbolic coin type. When the one after the call times out, h_entry copies a stored length it cannot fix and the run
# ends with NotConcreteError (it did once). When the one inside the save times out, the clean-up of an old long value
# runs with a symbolic bound and hits the loop bound. DA3r reads the default entry after the call as its two storage
# words, and writes the never written entry of the coin type again as its zeros before the call. The save's read then
# meets those zeros by its key alone, and a timeout elsewhere leaves only a word for the assertion solver.
default DefaultProofsTest test_check_DA3_otherCoinsKeepTheDefault 1800
# DA2z1 to DA2z3 and DA2e1 to DA2e3 are DA2z1r to DA2z3r and DA2e1r to DA2e3r. In Halmos 0.3.3 they depend on 1 ms
# queries that tell the default entry from the entry of the symbolic coin type. When one times out, the harness's save
# of that entry after the default (in the start state) or the call's save of the default cleans up an old long value
# with a symbolic bound and hits the loop bound, and h_entry of that entry after the call copies a stored length it
# cannot fix and ends with NotConcreteError. The r versions write each entry again as the words it holds, checked first,
# right before the reads that would pass the other entry, and read that entry after the call as its two storage words.

# DA1 is DA1r60 with DA1rHi, and DA1n is DA1nr. In Halmos 0.3.3 both depend on a 1 ms query in their start state, which
# writes the default entry and then the entry of the symbolic coin type. That second save reads the old value of its
# entry past the default entry's stores, and only the query tells the two keys apart. When it times out, the clean-up
# of an old long value runs with a symbolic bound and hits the loop bound (DA1n did once, a PASS with that warning).
# The robust proofs check that the never written entry of the coin type is zero and write it again as its zeros before
# the save, so the save's reads meet those zeros by their key alone. That needs the test and the harness to build the
# key from the same term. Once a path holds coinType == 60, Halmos hands 60 to a callee that reads the coin type from
# its calldata while the test still holds the symbol, so DA1 is split where its assumption branches: DA1r60 fixes the
# coin type at 60, where every key is built from constants, and DA1rHi takes the EVM coin types above the default with
# no equality in its assumptions. The only reads left that pass a store of the other key are the checked reads of the
# zeros, which end in an assertion, and DA1rHi's reads of the default, which turn the value into 20 bytes with no copy
# and no loop.
default DefaultNonEvmProofsTest test_check_DA1n_noFallbackOutsideTheEvm 7200
